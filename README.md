# Relay

Clipboard and file sharing between your Android phone and tablet over the same Wi-Fi. Everything is encrypted with your pair code.

**Send without opening the app:**
- Select text → **Relay** in the selection menu
- Quick Settings tile **Send clipboard**, or the button on Relay's notification
- Share any photo, file or link → **Relay**

**Receive:** items are copied to the clipboard automatically (photos too), and saved to Pictures/Download/Movies → Relay.

APK: built by GitHub Actions on every push (see Releases).
